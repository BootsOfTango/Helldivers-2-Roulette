Helldivers 2 Chaos Roulette - Windows x64

1. Optional: compare the ZIP against the included .sha256 checksum before extracting.
2. Extract the entire ZIP before running the app.
3. Open the extracted folder.
4. Double-click "Helldivers 2 Chaos Roulette.exe".
5. Do not move only the .exe. It depends on the Electron runtime files and resources next to it.
6. Saved information is stored in your Windows user data folder for this app:
   %APPDATA%\Helldivers 2 Chaos Roulette\state.json

Use Results -> Export JSON to create a portable backup, and Results -> Import JSON to restore one.
